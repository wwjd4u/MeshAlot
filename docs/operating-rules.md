# Operating rules

1. Start with Google Cloud only and dual-stack IPv4/IPv6.
2. One agent can provide and consume compute.
3. Simulated accounting only during the POC.
4. Never add arbitrary shell or command execution.
5. Never expose PostgreSQL or local AI runtimes publicly.
6. Do not add AWS, Azure, payments, or full P2P before their gates.
7. Every milestone needs recorded build, test, pass/fail, and gate evidence.
